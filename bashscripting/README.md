# 🐚 Самостоятельная работа по Bash программированию

## 📚 Описание

Данный репозиторий содержит самостоятельную работу по программированию на **Bash**.

Все скрипты находятся в каталоге `bashScripting/`.  
Для разработки и тестирования использовались **VS Code**, **Git Bash** и **Ubuntu WSL**.

## 1️⃣ Приветствие пользователя

Файл: `1.sh`

Скрипт запрашивает имя пользователя и выводит приветствие.

Запуск:

```bash
sh 1.sh
```

Пример:

```text
Введите ваше имя: Алексей
Привет, Алексей!
```

---

## 2️⃣ Калькулятор суммы

Файл: `2.sh`

Скрипт запрашивает два числа и выводит их сумму.

Запуск:

```bash
sh 2.sh
```

Пример:

```text
Введите первое число: 10
Введите второе число: 25
Сумма: 35
```

# 🚀 GitHub Repository Analyzer

Файл: `github-stats.sh`

Дополнительное задание выполнено в **Ubuntu WSL**.

Скрипт использует публичный **GitHub API** и получает статистику указанного репозитория.

## Возможности

Скрипт отображает:

- 📦 название репозитория;
- ⭐ количество звёзд;
- 🔀 количество форков;
- 🐛 количество открытых issues;
- 👤 владельца репозитория;
- 📊 примерную активность репозитория.

Также реализованы:

- проверка наличия `curl`;
- проверка наличия `jq`;
- обработка ошибки ненайденного репозитория;
- обработка превышения лимита GitHub API;
- обработка других HTTP-ошибок;
- цветной вывод информации.

## Установка зависимостей

Для Ubuntu WSL:

```bash
sudo apt update
sudo apt install curl jq
```

## Запуск

```bash
sh github-stats.sh tensorflow/tensorflow
```

Или:

```bash
bash github-stats.sh tensorflow/tensorflow
```

Пример:

```text
╔════════════════════════════════════════╗
║   🚀 GitHub Repository Analyzer       ║
╚════════════════════════════════════════╝

📦 Репозиторий: tensorflow/tensorflow
⭐ Звёзды:       182347  (⭐)
🔀 Форки:        73891   (🔀)
🐛 Open Issues:  1847    (🐛)
👤 Автор:        tensorflow
📊 Активность:   Высокая (2 ч. назад)
```

> Количество звёзд, форков и issues зависит от текущего состояния репозитория и поэтому изменяется со временем.
